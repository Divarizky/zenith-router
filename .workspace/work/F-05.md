# F-05 — Minimal Dashboard UI

## Problem
Pengguna membutuhkan antarmuka visual yang cepat, ringan, dan mandiri untuk melihat status gateway, memantau penggunaan token harian, mengelola akun koneksi provider (tambah/edit/hapus API key dan proxy), serta mengubah pengaturan tanpa harus memanipulasi database SQLite atau file konfigurasi secara manual.

## Solution
zenroute menyediakan antarmuka dashboard web server-side rendered (SSR) menggunakan Hono JSX / HTML template bawaan dengan styling gelap (dark mode) minimalis. Dashboard terdiri dari 4 tab navigasi utama:
1. **Overview**: Status gateway aktif, port 20128, ringkasan token terpakai hari ini, dan jumlah akun online.
2. **Connections**: Manajemen akun provider (tambah akun baru, kelola proxy, hapus akun, dan lihat status cooldown/kuota).
3. **Usage & Quota**: Tabel dan metrik konsumsi token harian dan rincian per model.
4. **Settings**: Konfigurasi global (toggle API key access guard, toggle RTK, toggle Caveman).
Seluruh antarmuka di-render langsung oleh Hono tanpa build step atau framework frontend terpisah.

## User Stories
- (MUST) As a developer, I want to access `http://localhost:20128/` or `/dashboard` in my browser to see the gateway health, port, and quick stats.
- (MUST) As a developer, I want a web form to add and delete provider connections (API key, OAuth credentials, and optional proxy URL), so that I don't have to write manual SQL queries.
- (MUST) As a developer, I want to view a table of recent token usage aggregated by model and date, so that I understand which agent consumes the most quota.
- (SHOULD) As a developer, I want to toggle settings like RTK, Caveman, and requireApiKey directly from the web UI.
- (NICE) As a developer, I want a button to manually trigger OAuth token refresh or quota synchronization for an account.

## Acceptance Criteria
- AC-01: WHEN pengguna membuka `GET /` atau `GET /dashboard` THEN sistem SHALL me-render halaman Overview dengan status gateway, metrik ringkas token, dan daftar model aktif.
- AC-02: WHEN pengguna membuka tab Connections THEN sistem SHALL menampilkan seluruh akun terdaftar beserta tombol hapus, status cooldown, dan sisa kuota.
- AC-03: WHEN pengguna mengirim form penambahan koneksi (`POST /dashboard/connections`) THEN sistem SHALL memvalidasi input, menyimpannya ke database SQLite, dan me-redirect kembali ke tab Connections.
- AC-04: WHEN pengguna membuka tab Usage THEN sistem SHALL menampilkan tabel ringkasan token (input, output, total, durasi) yang dikelompokkan berdasarkan model.
- AC-05: WHEN pengguna membuka tab Settings THEN sistem SHALL menampilkan form pengaturan global dengan nilai tersimpan saat ini dari SQLite.
- AC-06: WHEN pengguna mengubah pengaturan (`POST /dashboard/settings`) THEN sistem SHALL memperbarui record di tabel `settings` dan menerapkan perubahan secara instan.
- AC-07: WHILE seluruh antarmuka web diakses THEN sistem SHALL menggunakan zero client-side build step dan bergantung murni pada SSR Hono dengan ukuran total halaman < 50 KB.

## Implementation Decisions
**Final**:
- Menggunakan HTML templating bawaan Hono / Hono JSX SSR tanpa runtime React di browser.
- Desain antarmuka menggunakan vanilla CSS modern embedded (dark palette, CSS grid/flexbox) tanpa library UI pihak ketiga agar tetap menjaga footprint < 5 MB.
- Form submissions menggunakan standard HTML form POST dengan redirect PRG (Post-Redirect-Get).

**Open**:
- Penambahan tombol salin cepat (Copy to clipboard) untuk endpoint URL dan curl command contoh.

## Testing Decisions
- **Seam(s)**:
  1. `src/ui/layout.js` — Template dasar HTML dan navigasi tab.
  2. `src/ui/pages/` — Modul render konten (`overview.js`, `connections.js`, `usage.js`, `settings.js`).
  3. `src/ui/index.js` — Route controller dashboard Hono.
- **Test Strategy**:
  - Integration tests dengan `app.request("/dashboard")` untuk memverifikasi HTTP 200 dan keberadaan elemen HTML kunci.
  - Form submission tests (`POST /dashboard/connections`) untuk memverifikasi penambahan koneksi ke SQLite.
- **Environment**: Node.js 22+ local test harness.

## Out of Scope
- Visualisasi grafik interaktif kompleks berbasis Chart.js atau D3 (cukup progress bars dan tabel).
- Sistem autentikasi multi-user dengan role-based access control.
