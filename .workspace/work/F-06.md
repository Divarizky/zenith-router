# F-06 — Security Hardening & Gateway API Keys

## Problem
Review 07-10-2026 menemukan zenroute bisa dipakai siapa saja tanpa batas. Server listen di `0.0.0.0`, CORS `*`, dashboard tanpa proteksi CSRF, nilai yang dirender tidak di-escape (stored XSS), dan setting `require_api_key` tidak pernah dibaca. Header auth klien juga menimpa kredensial provider yang tersimpan, stream diputus timeout total 60 detik, dan RTK mengubah isi file pada hasil tool.

## Solution
Mengadopsi pola API key 9router (key milik gateway dipisah dari kredensial provider, ada tabel sendiri, bisa diaktifkan/nonaktifkan, dicek hanya saat diwajibkan) dengan penyimpanan yang lebih aman, lalu menutup celah jaringan dan dashboard.

## Implementation Decisions
**Final**:
- Format key `zr_` + 32 byte `crypto.randomBytes` (base64url). Tabel `api_keys` hanya menyimpan hash SHA-256 dan prefix 10 karakter untuk tampilan. Key plaintext ditampilkan sekali di respons pembuatan (`Cache-Control: no-store`), tanpa redirect.
- SHA-256 tanpa salt cukup karena key ber-entropi 256 bit; KDF lambat hanya perlu untuk secret ber-entropi rendah.
- Header auth klien hanya dipakai untuk validasi key zenroute dan tidak pernah diteruskan ke upstream. Kredensial upstream selalu dari connection; tanpa connection aktif, gateway membalas 503.
- Default bind `127.0.0.1` (env `HOST`). Bind non-loopback otomatis mewajibkan API key.
- Dashboard dan `/api/*` hanya menerima klien loopback; POST ditolak bila `Origin` beda host atau `Sec-Fetch-Site` cross-site.
- Host guard menolak Host non-loopback saat bind loopback (proteksi DNS rebinding); pengecualian lewat `ZENROUTE_ALLOWED_HOSTS`.
- CORS dimatikan secara default; opt-in lewat `ZENROUTE_CORS_ORIGINS`. POST `/v1/*` wajib `Content-Type: application/json` supaya request lintas origin selalu butuh preflight.
- Timeout total diganti headers timeout (default 300 detik) dan idle timeout antar-chunk (default 120 detik).
- Settings token saver dibaca per request. Caveman default off. RTK hanya memproses teks yang diketik user.

## Out of Scope
- Login dashboard berbasis password/session (dashboard dibatasi ke loopback sebagai gantinya).
- Paket perbaikan berikutnya: registry provider dan executor khusus, tool calling di translator, translasi `/v1/messages`, `/v1/responses`, failover antar-akun, usage streaming, bug translator stream.
