# UI Restyle ala 9router (dark black & white)

## Tujuan
Dashboard zenroute tampil memakai UX 9router (sidebar, card, toggle, modal) dengan gaya visual dark black & white, section tetap seperti kondisi saat ini.

## Keputusan (dari grill)
- UX 9router, visual dark black & white, aksen putih.
- Section tidak berubah: Overview, Connections, Usage (gabung Quota), API Keys, Settings. Plus 1 halaman baru: Token Saver (dipisah dari Settings).
- Navigasi: sidebar kiri sederhana (logo + item ber-ikon), tanpa traffic-light.
- Connections: kartu grid per provider + tambah connection via modal.
- Usage & Quota: satu halaman, stat cards + kartu quota + tabel model.
- API Keys: modal sederhana untuk create/toggle/delete, list key di bawah.
- Settings: hanya require API key & info umum.

## Palet
- bg `#0a0a0a`, surface `#161616`, surface-2 `#1f1f1f`, border `#2a2a2a`, text `#fafafa`, muted `#a3a3a3`, danger/success/warning tetap semantik.
- Tombol primary: putih bg, teks hitam. Hover: abu terang. Badge: pill abu gelap.
